## HTTP 集成

先构建并在一个终端运行 `npm run start:accounts`，再在另一终端执行 `npm run test:http`。检查注册 Cookie、拒绝跨来源、忽略伪造角色、报名/重复拒绝/取消、退出后旧会话失效和再次登录。脚本不打印密码或令牌，会在 `.data/accounts` 留下虚构测试账号，不连接云端。

## 静态产物

```sh
NEXT_PUBLIC_CAMPUS_CLOUDBASE_ENV_ID=campus-ci-placeholder npm run build:cloud
npm run check:artifact
```

占位 ID 仅用于无凭证构建验证，不能用于真实登录。检查根目录、auth、demo 入口及引用的脚本样式存在，拒绝 API、环境文件、本机数据库和 node_modules 路径。它不是完整敏感值扫描或安全审计。静态构建会改变 `.next` 的输出类型，切回本机服务器前重新 `npm run build`。

## 自有云端的匿名拒绝

```sh
NEXT_PUBLIC_CAMPUS_CLOUDBASE_ENV_ID=你的公开环境ID npm run test:cloud-anonymous
```

实际共享测试环境已测六项均返回 HTTP 401：匿名读取三表、匿名活动接口、伪造演示身份和无效令牌。脚本不使用有效会话，不打印响应正文，不写入记录。
