# 免登录交互演示

[在线体验](https://our-little-space-d9evhay4626495b-1526450049.tcloudbaseapp.com/campus/demo/)

这是面向项目评审的虚构数据演示。没有真实账号、持久化、多设备同步或生产权限授权；刷新后恢复初始四场活动，不修改真实云端空间。

## 三分钟体验

1. 默认是模拟学生林同学。打开第一场活动，取消后重新报名，查看名额和“我的报名”的变化。
2. 查看名额已满或报名截止的活动，观察按钮限制；按分类、关键词搜索活动。
3. 右上角切换到模拟组织者许老师，进入活动管理。打开第一场活动的名单，搜索、筛选已签到/待签到同学，导出当前筛选名单。
4. 为未签到的模拟同学点击“核验到场”，二次确认后观察统计变化。
5. 可自行发布未来的演示活动，切换模拟学生报名，再切回发布者签到。刷新页面后，临时活动和操作重置。

## 工程实现与边界

- `src/lib/showcase.ts` 是纯内存虚构数据模型，无 fetch、数据库或浏览器持久存储调用。
- `transportFor` 显式选择数据通道；即使构建配置 CloudBase，showcase 模式仍进入虚构数据通道，不读取 SDK 会话。
- 复用真实产品的界面组件，便于观察加载、空状态、确认、成功反馈和导出操作。
- 演示中的角色和名额规则用于交互说明，不是安全边界。真实版依赖 PostgreSQL RLS、受保护 RPC、平台认证和事务。
- 真实云端发布、空名单以及此前学生报名/取消已验收；真正的第二学生账号到组织者签到浏览器闭环尚未完成。详见 [验证说明](TESTING.md) 与 [架构说明](ARCHITECTURE.md)。

本机运行 `npm run dev` 后访问 `/demo/`，不需要提供云环境 ID 或任何密钥。
